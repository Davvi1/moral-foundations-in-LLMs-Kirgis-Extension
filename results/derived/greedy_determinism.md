# Is `greedy` reproducible across runs? — measured

Generated by `scripts/audit_greedy_determinism.py`. No GPU required: this compares the v1 and v2 collections, which independently ran the same models.

## Controls

- models in both collections: **20**
- cells compared, byte-identical prompt asserted per item: **2320**
- cells skipped because the prompt differed: **0**
- GPU model(s) across both runs: NVIDIA RTX PRO 4500 Blackwell
- package versions identical across the two collections: **yes**
  - `{"torch": "2.11.0+cu130", "transformers": "5.14.1", "vllm": "0.26.0"}`
- what deliberately differs: v2 runs six conditions where v1 ran four, so **batch composition differs**. That is the perturbation the caveat names.

## Result

| | count | share |
|---|---:|---:|
| raw text differs | 245 | **10.56%** |
| parsed score differs | 53 | **2.28%** |

Where the score moved: mean |shift| **1.038**, max **2.000** on a 0–4 scale.

**Text drift is largely cosmetic — the parser recovers the same digit from `"3"` and `"3: Very wrong"`. The score column is the one that reaches the analysis.**

## Verdict

**`greedy` is NOT reproducible across runs.** The caveat flagged in `METHODS_EXPLAINER.md` §3 and `LIMITATIONS.md` §12 is real and now measured: 2.28% of scores move between two runs of the same model, on the same prompt, same GPU model and same package versions.

**What this does and does not establish.** It establishes that a 'deterministic' arm is not reproducible run-to-run. It does *not* isolate batch composition as the cause — v1 and v2 differ in more than batching — so the mechanism remains the documented hypothesis, not a demonstrated one. Ruling out the obvious alternatives (prompt, GPU model, library versions) is what the Controls section above is for.

**Consequence for the design.** Of the arms described as deterministic, greedy is the one that generates text, and generation is where the instability lives. Re-running it is therefore not 'measuring a ruler twice' — a claim `METHODS_EXPLAINER.md` §5 makes about the deterministic arms collectively and which does not hold for this one.
