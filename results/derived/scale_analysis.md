Probability readouts only (`label`, `string_line`, `string_bare`). Free generation loses whole models to refusal and empty output, so a scale slope over it would confound scale with which models happened to survive.


## The compression confound, and why the primary is the adjusted gap

Compression itself changes with scale, and enormously. Fitting
`score = a + b * human` per model, the Qwen ladder runs **b = 0.113 -> 1.059**:
the 0.5B model barely tracks the human baseline, the 72B model tracks it almost
1:1. Because pure compression predicts a NEGATIVE raw gap (correction C3), the
raw gap rises with scale **even if the moral profile never changes**. Reporting
the raw slope as evidence for the capability story would be measuring the
disappearance of compression and calling it morality.

Slope of `b` on log-parameters, pooled: **+0.4004** (p = 0.0000, n = 30). That is the confound, measured.
